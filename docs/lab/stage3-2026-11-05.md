# Stage 3 lab run with real clients, 2026-11-05

Real Graal clients under Wine played the stage 3 world: level NPCs, baddies,
bombs and player hits. Everything ran in a network namespace whose only
interface is loopback (`tools/lab-wine.md`). No public server and no real
player account were used. A second namespace ran GServer-v2 beta4 as a black
box, to see what it sends; none of its code was read or used.

## Setup

- Server: the stage 3 branches as each was opened (PRs #37 to #40),
  `cargo build --release`, run with `--verbose`.
- Clients: real 2.22 (`GNW03014`) and real 2.05 rev 2 (`GNW03081`), each on
  its own Xvfb display, both in one Wine prefix.
- Levels, all made for the lab: the stage 2 levels (`tools/lab-wine.md`), with
  NPCs and a gray soldier (`BADDY 36 26 0`, verses Halt!, Ouch!,
  Take that!) added to `onlinestartlocal.nw`.
- A small test client built on Seihai's client library logged in as a 2.22,
  printed the messages it got, and sent prepared messages at set times.

## Results

| stage | what was done | result |
|---|---|---|
| 3.1 NPCs | 2.05 and 2.22 in the start level, on and off the gmap | Both drew the NPCs and their images, and a push from one reached the other. 2.05 needed the file with its modification time, and 2.22 on a gmap needed the NPCs under the gmap's name (both fixed in #37). |
| 3.2 baddies | 2.22 led the level off the gmap, 2.05 followed | The 2.22 ran the soldier and the 2.05 drew it moving. 2.05 drew only the shadow when sent `.gif` images, so it gets `.png` (fixed in #38). A hit from the follower reached the leader, which hurt and killed the soldier. Mode 9 (dead) came 2.0 s after mode 5, as on beta4. |
| 3.3 bombs | the test client dropped bombs next to each real client | 2.05 drew the bomb and its blast. 2.22 drew it off the gmap. |
| 3.4 hits | see below | The server side works. The real clients did not take part. |

### Player hits (3.4)

- The test client hit the real 2.05 and the real 2.22 several times each,
  3 s apart, in the same level, and the server sent each hit to the victim in
  the beta4 shape. Neither client lost hearts or sent a kill claim.
  - The 2.05 runs are weak evidence: that player had 0 or 1 hearts left from
    an earlier run (see Findings).
  - The last 2.22 run had 3 full hearts, and the server logged both hits
    (`--verbose` now logs hits and kill claims). The 2.22 still drew 3 full
    hearts afterwards.
- The real 2.22 swung its sword four times at the test client, which stood
  next to it on its left. The 2.22 sent no hit.
- The tests with the server's own client code (`tests/hurt_death.rs`) pass,
  so the server relays hits and applies kill claims as beta4 does to a
  scripted client. What the real clients need before they hurt each other is
  still open.

## Findings

- **A player saved with 0 hearts logs back in with 0 hearts.** Both lab
  players had been killed by the soldier in an earlier run, and their accounts
  kept `HP 0`. The clients then drew no hearts at all. To check: what beta4
  gives a player who logs in dead.
- **Only one client can be active per Wine prefix.** Clicking one client's
  window marks the other `(paused)` for everyone. A real client against a real
  client, both active, needs two Wine prefixes.
- On a gmap, a 2.22 leader runs the baddies but sends no changes, and a 2.22
  did not draw a bomb from a sender with no gmap cell. beta4 sends no baddies to
  gmap players at all.
